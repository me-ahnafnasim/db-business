# Google Play graphic assets

- `play-icon-512.png`: 512×512 Play Store icon.
- `feature-graphic.png`: 1024×500 feature graphic.
- Phone screenshots must be captured from a Play-signed internal-test build. Do
  not use generated mockups as evidence of app behavior.

The icon master was generated with the built-in image-generation workflow using:

> A premium Android launcher icon for NoboSole, combining a modern sneaker-sole
> silhouette with an abstract N, centered on midnight navy, using warm gold and
> restrained cyan, with generous adaptive-icon safe padding and no words.

The feature graphic was generated with:

> A 1024×500 NoboSole Play feature graphic using the sole/N identity, midnight
> navy, gold and cyan, subtle wholesale shoe-box geometry, and the exact brand
> name NoboSole with no prices, discounts or third-party marks.
